ROI info for Donor 1/Donor 2 ST analyses. This file contains two sheets, one for each donor. Each sheet contains information on each ROI (ROI #, surface area, nuclei count, ROI Type, ROI #, and cluster assignment). For ROIs with multiple AOI subregions, there is a column “AOI Subcategorization” that clarifies layer number for contour-based ROIs and antibody-enrichment for segmentation-based ROIs.

Centroid data for Donor 1/Donor 2 ST analyses. This file contains two sheets, one for each donor. The first sheet contains gene expression for 18,676 genes for each of the six clusters in Donor 1. The second sheet contains gene expression information for the same 18,676 genes for each of the nine clusters in Donor 2. Analysis for Donor 1 and 2 clustering is outlined in Methods.

DE gene results for all DE comparisons for Donor 1/Donor 2. This file contains two sheets, one for each donor. The first sheet contains differential gene expression analysis results for the 17 DE comparisons made using Donor 1 ROIs. For each DE comparison, fold change, t-statistic, p-value, and adjusted p-value are reported for all 18,676 genes. The second sheet contains the same

differential gene expression analysis results for the 12 DE comparisons made using Donor 2 ROIs. Descriptions for each DE comparison are outlined in Methods.

LRpath results for all DE gene results in Source Data 3. This file contains two sheets, one for each donor. The first sheet contains LRpath results for each DE comparison made using Donor 1 ROIs. For each DE comparison, odds ratio, p-value, and false discovery rate are reported. The second sheet contains the same DE comparison results for the 12 comparisons made using Donor 2 ROIs. All gene ontology terms (biological process, molecular function, and cell compartment) were included in the analysis, as well as all KEGG terms.

Marker genes for oocytes, granulosa cells, and theca cells. This file contains three sheets, each with cell-type specific marker genes identified through ST analysis: 96 granulosa-specific genes, 76 oocyte-specific genes, and 45 theca-specific genes. For each sheet, gene expression is reported for each ROI in Donor 2, and each ROI is labeled by its cluster assignment (i.e. #1-9).

Centroid data for the 4 major cell types identified in scRNAseq. This file contains three sheets, one for each scRNAseq donor. For each sheet, expression of 20,886 genes and detection rate is reported for the centroid of each major cell type cluster (Endothelial, Immune, Pericyte, and Stromal). This data is used for the dot plot in Figure 5C.

Centroid data for the 4 immune cell subtypes identified in scRNAseq. This file contains one sheet of gene expression information for the three donors’ immune cells combined (n = 836). For each of 20,886 we report gene expression and detection rate for each of the four immune cell subtypes (NK cells, T cells, macrophages, and mast cells).

Centroid data for marker genes for 3 major cell types and 4 immune cell subtypes. This file contains one sheet of gene expression for 331 marker genes portrayed in Figure 5D, with a number of markers for each cell type (endothelial, pericyte, stromal, NK cell, T cell, macrophage, and mast cell).
